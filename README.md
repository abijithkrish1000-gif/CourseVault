# 📚 CourseVault – Course Material Management Platform

CourseVault is a web-based platform designed to organize and manage teaching materials efficiently. It helps users maintain course folders, upload learning resources, track file versions, and manage archived materials in one place.

## 🚀 Features

- **Dashboard:** Displays an overview of courses, teaching files, and file versions.
- **Course Folders:** Organizes materials according to different subjects.
- **Upload Materials:** Allows users to add teaching resources.
- **Search and Filter:** Helps users find materials quickly.
- **Version History:** Keeps track of different versions of uploaded files.
- **Archive and Restore:** Allows users to archive and restore materials.
- **Activity History:** Displays recent changes and updates.
- **Access Controls:** Provides Admin, Editor, and Viewer roles.

## 🛠️ Technologies Used

- **HTML5** – Structure of the website.
- **CSS3** – Styling, layout, colors, and visual effects.
- **JavaScript** – Website functionality and interactive features.
- **LocalStorage** – Stores project data in the browser.

## 🎨 Design

The website uses a dark-themed interface with red highlights.

Some CSS features used include:
- Background colors
- Padding and margins
- Borders and border-radius
- Hover effects
- Focus effects
- Text styling

## 💻 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Explore the different sections of CourseVault.

No additional installation is required.

## 🎯 Project Objective

The objective of this project is to demonstrate the use of HTML, CSS, and JavaScript in developing a structured and interactive website.

It also provides a practical example of organizing educational resources through a simple web interface.
